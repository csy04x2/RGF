# Methodology

## SOURCE / ANALYSIS BOUNDARY

항상 다음을 구분한다.

1. SOURCE-DERIVED FACT / CHANGE
2. AI-ASSISTED ANALYTICAL IMPLICATION
3. UNKNOWN
4. REPORTING QUESTION
5. EVIDENCE NEEDED / REPORTING ACTION

방법론 설명 예시:

- Source: 법정형이 5년 → 7년으로 변경.
- 잘못된 결론: “실형 가능성이 높아졌다.”
- 올바른 분석: “법정형 상향이 실제 기소·양형 결과에 어떤 영향을 미치는지 확인할 필요가 있다.”

실제 양형 변화는 외부 취재 전까지 UNKNOWN이다.

## EVIDENCE STATUS

Evidence status는 제공된 source 내부의 근거 수준만 평가한다.

- **SUPPORTED:** source 내부에 구체적 근거가 있음.
- **PARTIALLY SUPPORTED:** 일부 근거는 있지만 중요한 정보가 빠짐.
- **ASSERTION ONLY:** source가 주장하지만 source 내부의 구체적 근거가 없음.

SUPPORTED는 사실임, 독립 검증됨, 팩트체크 완료 또는 진실을 의미하지 않는다.

## SOURCE-LEVEL GAP TAXONOMY

Source 자체에서 빠진 정보에 대해 다음만 사용한다.

- BASELINE
- DENOMINATOR
- DEFINITION
- TIME
- EVIDENCE
- PERSPECTIVE

## HIGHER-ORDER REPORTING LENSES

다음 lens는 필요할 때만 사용한다. 모든 lens에서 억지로 finding을 만들지 않는다.

- IMPLEMENTATION
- OUTCOME
- MEASUREMENT
- PROBLEM–RESPONSE FIT
- LEGAL / REGULATORY BOUNDARY
- AFFECTED-PARTY PERSPECTIVE
- ACCOUNTABILITY / FOLLOW-UP
- INTERNAL TENSION / DEPENDENCY
- BURIED SIGNIFICANCE

## PROVENANCE

중요한 discovery는 가능하면 다음으로 원문까지 추적 가능해야 한다.

- SOURCE PAGE
- SOURCE SECTION
- SOURCE EXCERPT
- SOURCE BASIS

원본 source가 provenance의 최종 authority다.

## Benchmark 철학

Canonical benchmark fixture는 이후 제공될 예정이다. Benchmark의 목적은 기존 Opal output과 문자열을 동일하게 재현하는 것이 아니다. 기존 Opal JSON은 GOLD ANSWER가 아니라 **legacy baseline**이다.

Standalone 평가 기준:

- source fidelity
- meaningful reporting discovery
- provenance
- source/analysis separation
- relationship integrity
- schema validity
- no information loss
- no unsupported external contamination
