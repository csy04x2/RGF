# Regression tests

향후 executable regression tests는 다음을 보호한다.

- schema integrity
- ID integrity
- relationship integrity
- provenance integrity
- unsupported premise sanitization
- renderer object preservation
- renderer non-invention

실제 fixture가 migration된 후 구현한다. Foundation-01에서는 테스트 framework를 선택하거나 설치하지 않는다.
